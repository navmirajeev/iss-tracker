# iss-tracker

A space-inspired International Space Station tracking dashboard featuring live orbital telemetry, an interactive 3D Earth globe and a geographic view of the station's current position.

# Features

Live ISS telemetry: Displays altitude, velocity, latitude and longitude.

Interactive 3D Earth: Explore a three-dimensional globe with an approximate marker for the ISS's current ground position.

Station position map: View the station's approximate location on an interactive OpenStreetMap map.

Automatic updates: Fetches updated ISS data every five seconds.

Responsive interface: Adapts to desktop and mobile screen sizes.

Mission-control design: Dark navy backgrounds, blue atmospheric accents and telemetry-style information panels.
